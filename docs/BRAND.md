# Aether Brand

## Identity

The Aether mark is an original geometric system built from a central state node, three incomplete observation arcs, and one acid-lime convergence point. The interrupted orbits communicate continuous monitoring rather than passive storage; the aligned lime point communicates independently verified return to intent.

## Assets

- `apps/web/public/brand/aether-mark.svg` — primary dark-canvas mark.
- `apps/web/public/brand/aether-mark-mono.svg` — single-color mark for light surfaces and constrained output.
- `apps/web/public/brand/aether-wordmark.svg` — standalone wordmark.
- `apps/web/public/brand/aether-lockup.svg` — preferred navigation and document lockup.
- `apps/web/src/app/icon.svg` — favicon source.

## Usage

Keep clear space equal to the central node diameter. Use the mark at 16px or larger and the lockup at 96px or larger. Acid lime is reserved for the verified convergence point and the primary action; do not recolor the arcs with decorative gradients. On light backgrounds, use the monochrome asset in `#08090A`.
