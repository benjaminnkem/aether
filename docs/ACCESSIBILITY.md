# Accessibility

- WCAG 2.2 AA intent for critical frontend flows.
- Skip link and semantic main/navigation landmarks.
- Visible focus rings and keyboard-operable buttons, tables, command palette, menus, tabs, modals, and drawers.
- Radix Dialog provides focus trapping, Escape handling, and focus restoration.
- Icon buttons always receive accessible labels.
- Status is represented through icon, color, and text.
- Critical updates use live toast/notification regions.
- Dense tables expose captions and headers; mobile uses labeled cards.
- React Flow has a complete mobile/keyboard-readable timeline fallback.
- Reduced motion disables smooth scroll, transitions, WebGL animation, and nonessential state pulses.
- Three.js failure/reduced-motion/mobile contexts retain the static SVG field.
